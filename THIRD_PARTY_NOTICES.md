## 1. Module firmware (`firmware/`)

The firmware binary programmed into ATEK RF modules includes the following components.

| Component | Copyright | License | Location in repository |
|---|---|---|---|
| STM32F0xx HAL drivers | STMicroelectronics | BSD-3-Clause | `firmware/Drivers/STM32F0xx_HAL_Driver/` |
| CMSIS Core | Arm Limited | Apache-2.0 | `firmware/Drivers/CMSIS/` |
| CMSIS Device STM32F0xx | Arm Limited, STMicroelectronics | Apache-2.0 | `firmware/Drivers/CMSIS/Device/` |
| STM32 USB Device Library | STMicroelectronics | ST SLA0044 | `firmware/Middlewares/ST/STM32_USB_Device_Library/` |
| STM32CubeMX generated files (`main.c`, `usb_device.c`, `usbd_*.c`, ...) | STMicroelectronics | As stated in each file header | `firmware/Core/`, `firmware/USB_DEVICE/` |
| stm32-ssd1306 OLED driver | Aleksander Alekseev (2018); originally written by Olivier Van den Eede (2016) | MIT | `firmware/Core/` (`ssd1306.c/.h`, `ssd1306_fonts.c/.h`, `ssd1306_conf.h`) |


**Notes**

- The license files supplied by STMicroelectronics and Arm are kept in the
  directories listed above and must not be removed.
- The stm32-ssd1306 driver is taken from
  <https://github.com/afiskon/stm32-ssd1306> (folder `ssd1306/`).
  `ssd1306_conf.h` is the project configuration created from the library's
  `ssd1306_conf_template.h`.
- The 5x7 bitmap font table in `firmware/Core/Src/hw.c` is the classic
  5x7 ASCII font that is widely circulated without license restrictions.
  The drawing routine in the same file follows the approach of the Adafruit
  GFX Library but does not contain Adafruit code or font data.
- The STM32 USB Device Library is licensed under ST SLA0044, which permits
  use and redistribution only in connection with STMicroelectronics
  microcontrollers. Full terms: <https://www.st.com/SLA0044>
- Files generated by STM32CubeMX keep their original STMicroelectronics
  header. Code added by ATEK MIDAS inside the `USER CODE` sections of these
  files is licensed under the MIT License.
